# ultrafast on Linux / NVIDIA (L4 and friends)

On Linux ultrafast renders through its Vulkan backend (`crates/ultrafast-gpu/src/vulkan.rs`):
the same kernels, generated by the same Slang code, compiled to SPIR-V
instead of MSL. On macOS the same backend runs through MoltenVK
(`cargo build --features vulkan`), which is how it is tested: every GPU test
passes on both backends and their renders agree to within 1/255.

## Requirements

- NVIDIA driver with Vulkan 1.3 (any recent driver for L4) and the Vulkan
  loader (`libvulkan.so.1`, package `libvulkan1`).
- Slang: the release archives and the image bundle it, and a source build
  fetches the pinned release once on first use. To use your own, point
  `ULTRAFAST_SLANG_DIR` at the extracted folder from
  https://github.com/shader-slang/slang/releases (the one containing
  `lib/libslang.so`), or set `SLANG_DIR` when building.
- `ffmpeg` for `ultrafast export` (with `h264_nvenc` / `hevc_nvenc` it encodes on
  the GPU's NVENC; otherwise libx264/libx265).

## Build and check

```bash
cargo build --release
./target/release/ultrafast info          # backend: vulkan, device: NVIDIA L4
./target/release/ultrafast bench examples/hello.json --frames 2000
./target/release/ultrafast export examples/type.json out/type.mp4
```

`ultrafast live` runs headless on Linux (no preview window); drive it over the
JSON-lines socket exactly as on macOS.

## Current limits on this backend

- Video (`video` op) and sound decode through `ffmpeg` / `ffprobe`
  processes: frames arrive as BGRA bytes and are uploaded when used (counted
  as uploads), and a seek restarts the decoder at the target. Renders match
  the macOS VideoToolbox path within a few 1/255. The planned path is NVDEC
  decoding into CUDA memory exported to Vulkan (`VK_KHR_external_memory_fd`),
  zero-copy like VideoToolbox on macOS.
- Export reads frames back and pipes them to ffmpeg (counted as readbacks in
  `stats`); the document's sound is mixed and muxed as AAC. The planned path
  is NVENC fed from Vulkan images imported into CUDA, with no readback.
- This path runs on macOS too with `--features vulkan` (MoltenVK), which is
  how it is tested.
- Every dispatch is followed by a full compute/transfer barrier; finer
  barriers are an optimization for later.
- `ULTRAFAST_VULKAN_LIB` overrides the Vulkan loader path.
