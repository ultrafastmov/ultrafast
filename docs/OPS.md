# ultrafast ops

Every op, its input ports and its params (type = default: what it does). Generated by `ultrafast ops --markdown`.

## solid
flat color
- `color`: color = #000000 - fill color

## gradient
linear, radial or conic gradient
- `kind`: enum(linear|radial|conic) = linear - gradient shape
- `a`: color - start color (with b: a two-stop gradient)
- `b`: color - end color
- `stops`: text|number[] - "0:#ff0000, 1:#0000ff" or [pos,r,g,b,a,...], up to 8
- `space`: enum(linear|srgb) = linear - interpolation space; srgb matches CSS/Figma
- `start`: vec2 = [0,0] - linear: start point px
- `end`: vec2 = [0,h] - linear: end point px
- `center`: vec2 = frame center - radial/conic center px
- `radius`: number = max(w,h)/2 - radial radius px
- `angle`: number = 0 - conic start angle, degrees

## shape
analytic rectangle / rounded rect / ellipse (SDF, antialiased)
- `kind`: enum(rect|ellipse|circle) = rect - shape
- `color`: color = #ffffff - fill (or stroke) color
- `center`: vec2 = frame center - center px
- `size`: vec2 = [w/4,w/4] - width and height px
- `radius`: number = 0 - corner radius px
- `rotation`: number = 0 - degrees
- `scale`: number|vec2 = 1 - scale about the center (size, corners and stroke)
- `opacity`: number = 1 - 0..1, fades the shape
- `stroke`: number = 0 - outline width px; 0 fills
- `softness`: number = 1 - edge softness in output pixels

## checker
checkerboard
- `a`: color = #333333 - first cell
- `b`: color = #666666 - second cell
- `size`: number = 32 - cell px

## noise
fractal simplex noise between two colors
- `a`: color = #000000 - low color
- `b`: color = #ffffff - high color
- `scale`: vec2|number = [200,200] - px per noise cell
- `offset`: vec2 = [0,0] - pan px
- `evolution`: number = 0 - third noise dimension; animate it
- `octaves`: number = 4 - 1..8

## image
still image or image sequence
- `src`: text - file path relative to the document; {frame} / {frame:05} for sequences
- `fit`: enum(contain|cover|fill|none) = contain - placement in the frame, or in `rect` (cover there by default); only fill stretches
- `rect`: vec4 - [x,y,w,h] px box the picture goes in, by `fit`; it keeps its aspect ratio
- `opacity`: number = 1 - 0..1
- `space`: enum(linear|srgb) = linear - interpolation space when scaled; srgb filters the encoded values as browsers do
- `fps`: number = document fps - sequence frame rate
- `first_frame`: number = 0 - sequence frame number at local time 0

## video
video clip, hardware decoded
- `src`: text - file path
- `fit`: enum(contain|cover|fill|none) = contain - placement in the frame, or in `rect` (cover there by default); only fill stretches
- `rect`: vec4 - [x,y,w,h] px box the footage goes in, by `fit`; it keeps its aspect ratio
- `opacity`: number = 1 - 0..1
- `space`: enum(linear|srgb) = linear - interpolation space when scaled; srgb filters the encoded values as browsers do
- `start`: number = 0 - source seconds at local time 0
- `speed`: number = 1 - playback rate
- `loop`: bool = false - wrap at the clip's end (else hold the last frame)
- `time`: number - explicit source time (animate for time remapping)

## path
vector path (SVG data or preset), GPU exact-coverage raster
- `to`: text - SVG path data to morph toward; several separated by | to morph through each in turn
- `morph`: number = 0 - 0 = this path, 1 = `to` (with several targets, 2 = the second, ...); animate it
- `d`: text - SVG path data
- `kind`: enum(star|polygon|circle|line|polyline|polygon_points) - preset instead of d
- `center`: vec2 = frame center - preset center
- `radius`: number = h/4 - preset radius
- `sides`: number = 5 / 6 - star points / polygon sides
- `inner_radius`: number = 0.45 r - star inner radius
- `points`: number[] - flat [x0,y0,x1,y1,...] for line/polyline/polygon_points
- `color`: color = #ffffff - paint
- `opacity`: number = 1 - 0..1, fades the whole node (animate for fades)
- `fill_rule`: enum(nonzero|evenodd) = nonzero - fill rule
- `trim_start`: number = 0 - 0..1 of length
- `trim_end`: number = 1 - 0..1 of length (animate for draw-on)
- `stroke`: number = 0 - stroke width px; 0 fills
- `join`: enum(miter|round|bevel) = miter - stroke joins
- `cap`: enum(butt|round|square) = butt - stroke caps
- `dash`: number[] - dash pattern [on, off, ...] px
- `dash_offset`: number = 0 - dash phase px
- `position`: vec2 = [0,0] - where the anchor lands, px
- `anchor`: vec2 = [0,0] - pivot in the node's own space, px
- `scale`: vec2|number = [1,1] - scale around the anchor
- `rotation`: number = 0 - degrees, clockwise

## text
shaped text, GPU exact-coverage raster
- `text`: text - content; \n breaks lines; *word* is emphasis (em_ params), [words]{color=#ffd23f highlight=#ff4d6d} styles a span
- `font`: text = Helvetica Neue - family name or font file path
- `weight`: number = 400 - 100..900
- `style`: enum(normal|italic) = normal - style
- `size`: number = 64 - px
- `color`: color = #ffffff - paint
- `opacity`: number = 1 - 0..1, fades the whole node (animate for fades)
- `align`: enum(left|center|right) = left - horizontal anchor of each line
- `valign`: enum(top|middle|baseline|bottom) = top - vertical anchor of the block
- `width`: number - wrap width px
- `line_height`: number = 1.2 - multiple of size
- `tracking`: number = 0 - extra px between glyphs
- `features`: text - OpenType features, e.g. "liga=0,ss01"
- `variations`: text - variable-font axes, e.g. "wdth=80, opsz=144" (weight drives wght; opsz follows size unless set)
- `axis_<tag>`: number = axis default - one variable-font axis, animatable: axis_wdth, axis_SOFT
- `stagger`: number = 0 - seconds between glyphs for the glyph_* animators
- `stagger_order`: enum(forward|reverse|center|random) = forward - which glyphs go first
- `glyph_offset`: vec2 = [0,0] - per-glyph offset px, keyed in glyph time (t - stagger * order)
- `glyph_scale`: vec2 = [1,1] - per-glyph scale about the glyph's center, glyph time
- `glyph_rotation`: number = 0 - per-glyph rotation degrees, glyph time
- `glyph_opacity`: number = 1 - per-glyph opacity, glyph time
- `reveal`: number = all - glyphs visible (fractional fades)
- `reveal_softness`: number = 1 - glyphs the reveal fade spans
- `reveal_offset`: vec2 = [0,0] - offset of not-yet-revealed glyphs px
- `fill_rule`: enum(nonzero|evenodd) = nonzero - fill rule
- `skim`: bool = false - glanced at, not read (code, data labels): ultrafast review skips its reading-time check
- `markup`: bool = true - parse inline styling in text: *emphasis* and [words]{color=#ffd23f weight=800 font="ultrafast:serif" style=italic size=80 highlight=#ff4d6d underline=4 underline_color=#fff rise=10 draw=1}
- `em_color`: color = text color - color of *emphasis*
- `em_font`: text = font - face of *emphasis* (e.g. ultrafast:serif for a serif accent)
- `em_weight`: number = weight - weight of *emphasis*
- `em_style`: enum(normal|italic) = italic when no em_ param is set - style of *emphasis* (italic is synthesized for faces without one)
- `em_size`: number = size - size px of *emphasis*
- `em_highlight`: color = none - marker box behind *emphasis*
- `em_underline`: number = 0 - underline thickness px under *emphasis*
- `em_underline_color`: color = em_color - underline color
- `em_rise`: number = 0 - baseline shift px of *emphasis* (up)
- `em_draw`: number = 1 - share of the emphasis highlights and underlines drawn, 0..1, one stroke across lines in reading order (animate it)
- `on_path`: text - SVG path data the text follows (closed paths wrap: circular badges); align picks start, middle or end
- `path_offset`: number = 0 - px along the path; animate it to run text along
- `number`: number - show this value instead of text (animate it: counters)
- `decimals`: number = 0 - digits after the point for number
- `thousands`: text = , - group separator for number ("" for none)
- `prefix`: text - before number, e.g. $
- `suffix`: text - after number, e.g. % or k
- `scramble`: number - decoding text: animate 0 (all random) to 1 (the text)
- `scramble_chars`: text = A-Z, 0-9, symbols - characters the undecoded ones cycle through
- `stroke`: number = 0 - stroke width px; 0 fills
- `join`: enum(miter|round|bevel) = miter - stroke joins
- `cap`: enum(butt|round|square) = butt - stroke caps
- `dash`: number[] - dash pattern [on, off, ...] px
- `dash_offset`: number = 0 - dash phase px
- `position`: vec2 = [0,0] - where the anchor lands, px
- `anchor`: vec2 = [0,0] - pivot in the node's own space, px
- `scale`: vec2|number = [1,1] - scale around the anchor
- `rotation`: number = 0 - degrees, clockwise

## shader(in0, in1, in2, in3)
agent-written Slang: float4 shade(float2 pos, float px)
- `resolution`: number = 1 - render at this fraction of the frame size and upscale (soft, costly looks; write shaders with pos/size())
- `code`: text - Slang source defining shade(); `static const` tables of 64+ numbers are read from the params (editing their values compiles nothing)
- `u`: number[] - up to 16 values, param(i)
- `u0`: number - u0..u15 individually (animatable)
- `motion_blur`: bool = false - true: the format's motion blur samples its clock and animated u values (a shader that moves things); otherwise it holds at the frame's time

## mesh(texture)

- `text`: text - primitive text: content
- `font`: text = Helvetica Neue - primitive text: family or file
- `weight`: number = 400 - primitive text: weight
- `style`: enum(normal|italic) = normal - primitive text: style
- `size`: number = 1 - primitive text: size in world units
- `align`: enum(left|center|right) = center - primitive text: alignment
- `tracking`: number = 0 - primitive text: extra spacing (px at 100 px/unit)
- `line_height`: number = 1.2 - primitive text: multiple of size
- `d`: text - primitive path: SVG path data
- `units`: number = 100 - primitive path: path px per world unit
- `depth`: number = 0.25 - extrusion depth, world units
- `bevel`: number = 0 - text/path: 45-degree chamfer on both rims, world units
- `src`: text - .gltf/.glb file instead of a primitive
- `segments`: number = 32 - tessellation
- `position`: vec3 = [0,0,0] 
- `rotation`: vec3 = [0,0,0] - degrees, X then Y then Z

- `font`: text = Helvetica Neue - font family or file
- `weight`: number = 400 - font weight
- `style`: enum(normal|italic) = normal - font style
- `tracking`: number = 0 - extra px between glyphs
- `variations`: text - variable-font axes, as on text
- `axis_<tag>`: number = axis default - one variable-font axis, as on text
- `size`: number = 64 - text size px
- `position`: vec2 = [0,0] - text position (as `text`)
- `align`: enum(left|center|right) = left - text alignment
- `valign`: enum(top|middle|baseline|bottom) = top - vertical alignment
- `count`: number = 4000 - particles
- `progress`: number = 1 - 0 scattered, 1 formed; animate it
- `stagger`: number = 0.5 - spread of arrival times (fraction of progress)
- `scatter`: number = 700 - how far particles start from home, px
- `origin`: vec2 - start every particle from this point instead
- `turbulence`: number = 40 - drift amplitude while away from home, px
- `particle_size`: vec2 = [2,3] - size scattered and formed, px
- `color`: color = #ffffff - color when formed
- `color_scatter`: color = color - color when scattered
- `shimmer`: number = 0 - 0..1 twinkle
- `stretch`: number = 0 - streak along travel while moving
- `seed`: number = 1 - random seed
- `blend`: enum(over|add) = over - how particles combine

## fluid(dye, stir)
ink/smoke simulation: `dye` pours color in, `stir` pushes it around; stepped once per frame (exact on export, seekable)
- `start`: number = 0 - local time the simulation starts (blank before)
- `emit`: number = 6 - how fast `dye` replaces the fluid where it is, per s
- `dissipation`: number = 0.15 - dye fade per s
- `velocity_dissipation`: number = 0.4 - motion fade per s
- `vorticity`: number = 4 - keeps eddies curling (0 = silky, 10+ = churning)
- `turbulence`: number = 0 - curl-noise stirring, px/s^2 (try 400..3000)
- `turbulence_scale`: number = 260 - size of the noise eddies, px
- `wind`: vec2 = [0,0] - drift of everything, px/s
- `buoyancy`: number = 0 - dye rises (smoke), px/s^2 per unit alpha
- `stir`: number = 2500 - push away from the edges of the `stir` image
- `swirl`: number = 0 - spin around the edges of the `stir` image
- `resolution`: number = 0.25 - velocity grid, fraction of the frame
- `dye_resolution`: number = 0.5 - dye grid, fraction of the frame
- `pressure_iterations`: number = 24 - incompressibility solver iterations
- `substeps`: number = 1 - steps per frame (1..8)
- `seed`: number = 1 - turbulence pattern

## raymarch(in0, in1, in2, in3)
3D as a signed-distance scene marched per pixel: write float2 map(float3 p) -> (distance, material id); soft shadows, occlusion, a reflection bounce, environment and antialiasing come with it
- `scene`: text - Slang: float2 map(float3 p) (+ optional void material(float id, float3 p, float3 n, inout float3 albedo, inout float metallic, inout float roughness)); helpers sdSphere, sdBox, sdCylinder, sdTorus, sdCapsule, sdBand, sdPlane, smin, opU, rotX/Y/Z, fbm3, knob(i), layerDistance + extrude (any ultrafast layer as a 3D solid), presetMaterial (ids 0 matte, 1 brass, 2 polished brass, 3 steel, 4 gold, 5 copper, 6 black lacquer, 7 ceramic, 8 rubber, 9 clear glass, 10 chrome; metallic < 0 makes glass); input(i, px) reads in0..in3
- `orbit`: vec3 = [30,20,8] - camera [azimuth, elevation, distance] around target, degrees and world units
- `target`: vec3 = [0,0,0] - what the camera looks at
- `fov`: number = 35 - vertical, degrees
- `light`: vec3 = [-4,5,4] - point light position (casts soft shadows)
- `light_color`: color = #fff2e0 - light color
- `light_intensity`: number = 40 - inverse-square intensity
- `environment`: enum(studio|room|night|sky|lightbox|horizon) = studio - what reflections and ambient light see (lightbox: bars of light, made for glass and chrome)
- `background`: text = environment - environment, transparent (to composite over 2D), or a color
- `background_level`: number = 0.35 - brightness of an environment background
- `exposure`: number = 1 - before tone mapping
- `samples`: number = 2 - rays per pixel (1..8), jittered
- `bounce`: bool = true - trace one reflection bounce for glossy surfaces
- `ior`: number = 1.5 - glass index of refraction (materials with metallic < 0, preset 9)
- `dispersion`: number = 1 - glass color splitting (0 none, 2 strong)
- `max_distance`: number = 80 - rays stop here
- `k0`: number - k0..k4: free knobs read as knob(0..4) in the scene (animatable)
- `resolution`: number = 1 - render scale

## transition(a, b)
from shot `a` to shot `b` over `duration` s starting `at`: only a renders before, only b after
- `kind`: enum(crossfade|dip|wipe|push|slide|iris|zoom|dissolve|glitch|blur) = crossfade - how: dip goes through `color`; wipe/push/slide move along `direction`; iris opens from `center`; dissolve burns through noise
- `at`: number = 0 - start, seconds
- `duration`: number = 0.8 - seconds
- `direction`: number = 0 - degrees: 0 moves rightward, 90 downward
- `softness`: number = per kind - edge softness (blur: strength)
- `color`: color = #000000 - dip color; wipe and dissolve edge glow color (dissolve: ember #ff9a4a)
- `glow`: number = 0 (dissolve 2) - edge glow strength
- `center`: vec2 = frame center - iris and zoom center px
- `grain`: number = 160 - dissolve noise size px
- `ease`: text|number[] = per kind - progress easing: a name (in_out_cubic) or [x1, y1, x2, y2]

## block
a ready-made animated block in one house style: title, lower_third, quote, stat, chapter, end_card, and charts: bar_chart, line_chart, donut (place it in time with a timing offset)
- `kind`: enum(title|lower_third|quote|stat|chapter|end_card|bar_chart|line_chart|donut) = title - which block
- `title`: text - title / chapter / end_card / charts (above the chart)
- `kicker`: text - title, charts: small line above
- `subtitle`: text - title: line below
- `number`: text - chapter: its number, e.g. 01
- `name`: text - lower_third
- `role`: text - lower_third
- `quote`: text - quote
- `author`: text - quote
- `value`: number = 0 - stat: counts up to it
- `prefix`: text - stat, bar and line values
- `suffix`: text - stat, bar and line values
- `decimals`: number = 0 - stat, bar and line values
- `label`: text - stat
- `tagline`: text - end_card
- `cta`: text - end_card: a pill button
- `logo`: text - end_card: SVG file
- `values`: number[] - charts: the data, e.g. [24, 31, 58, 265]
- `labels`: text - charts: one per value, comma separated (or | when labels hold commas)
- `highlight`: number = bar, donut: the largest; line: the last - charts: index of the value set in the accent and called out (-1: none)
- `height`: number = 34% of the height - charts: plot height px
