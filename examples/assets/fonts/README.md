# Fonts

Open-source fonts from [Google Fonts](https://github.com/google/fonts) under
the SIL Open Font License 1.1 (licenses in `licenses/`), for the examples.
Files named `-VF` are variable fonts; ultrafast drives their axes from `weight`,
`variations` and `axis_<tag>` params.
